# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it responsibly.

- Email: security@niphas.io
- Expected response time: within 48 hours
- We will provide a fix within 30 days of disclosure

## Supported Versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Disclosure Policy

We follow coordinated vulnerability disclosure. Please do not open public
issues for security vulnerabilities.
